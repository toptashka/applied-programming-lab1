# Система управления спортивным клубом

Лабораторная работа по прикладному программированию (Лабораторная работа № 1 «ООП в Python. Обработка исключительных ситуаций. Форматы XML и JSON»). 

Консольное приложение для управления спортивными секциями. Позволяет регистрировать пользователей (менеджеров, тренеров и спортсменов), составлять расписание тренировок и турниров, управлять тренировочными группами, спортивным инвентарем и медицинскими допусками.

## Запуск

Для работы требуется Python версии 3.10 или новее. Запустите файл `main.py` в вашей IDE (например, PyCharm) или из командной строки в папке проекта:

```bash
python3 main.py
```

В главном меню программы вы можете войти по вашему числовому ID, зарегистрировать нового пользователя, а также импортировать или экспортировать базу данных. Состояние приложения хранится локально и может быть сохранено в файлы (по умолчанию `data.json` или `data.xml`).

## Структура проекта

Код написан в объектно-ориентированном стиле, разделен на логические модули и использует аннотацию типов.

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа в программу, глобальное хранилище данных, консольное меню и обработчики ввода/вывода. |
| `models.py` | Описание классов предметной области: сущности пользователей (`Person`, `Manager`, `Coach`, `Athlete`), мероприятий (`Event`, `TrainingSession`, `Tournament`), инфраструктуры (`Location`, `Equipment`) и другие. |
| `services.py` | Бизнес-логика: планирование мероприятий с проверкой пересечений времени, управление группами, регистрация на турниры, логика выдачи наград. |
| `storage.py` | Сериализация и десериализация объектов. Считывание и запись базы данных в форматах **JSON** и **XML**. |
| `exceptions.py` | Иерархия пользовательских исключений для валидации форматов данных (`InvalidFormatError`) и контроля бизнес-правил (`BusinessLogicError`). |

## Пример работы

1. При первом запуске выберите пункт `[6] Register new user`, чтобы создать профиль, например, Менеджера (потребуется ввести ID, имя, телефон и уровень доступа).
2. Выберите пункт `[1] Login by ID` и введите ID созданного пользователя.
3. В меню менеджера выберите пункт `[9] Add sport`, чтобы добавить новый вид спорта.
4. Выберите пункт `[7] Add equipment`, чтобы добавить инвентарь для созданного спорта.
5. Для завершения работы нажмите `[0] Logout`, затем в главном меню выберите пункт `[3] Export to JSON`, чтобы сохранить созданные объекты в файл `data.json`.
6. При следующем запуске используйте пункт `[2] Import from JSON` для загрузки сохраненных данных.

## Роли пользователей и права доступа

- **Менеджер:** Управляет расписанием локаций, планирует тренировки и турниры, добавляет инвентарь и виды спорта. Доступ к некоторым действиям (например, отмена мероприятий) ограничен уровнем доступа менеджера (Access Level).
- **Тренер:** Создает тренировочные группы, добавляет в них спортсменов, отмечает посещаемость на своих занятиях и выдает спортивные достижения.
- **Спортсмен:** Может просматривать свое расписание (тренировки и турниры), список наград и профиль, а также обновлять статус своей медицинской справки.

## Правила и обработка ошибок

Система строго контролирует вводимые данные с помощью собственных классов исключений:
- Номер телефона должен соответствовать формату `+7XXXXXXXXXX` или `8XXXXXXXXXX`.
- Даты (рождения, мероприятий, справок) должны быть в формате `DD.MM.YYYY` или `DD.MM.YYYY HH:MM`. Нельзя указывать дату рождения в будущем.
- Нельзя записать спортсмена на турнир, если у него нет действующей медицинской справки.
- Нельзя запланировать мероприятие в локации, если на это время уже назначено другое событие.
- При возникновении ошибки (неверный формат, конфликт расписания, отказ в доступе) программа не "падает", а перехватывает исключение и выводит понятное текстовое сообщение пользователю, возвращая его в меню.
